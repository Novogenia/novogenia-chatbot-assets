## Blood Test vs. Genetic Test

### When should I use a blood test vs. a genetic test?

A blood test measures current values (a snapshot) — useful for monitoring deficiencies and adjusting therapy. A genetic test reveals innate metabolic properties — useful for identifying root causes and lifelong personalization. Blood tests are repeated regularly and often require fasting. Genetic tests are done once (genes don't change) and require no fasting.

### Are blood tests necessary for responsible supplementation?

The more data available, the better — but they are not strictly required. The genetic test alone can already provide meaningful, personalized recommendations. A blood test optimally complements this.
